# Drum Chief
An app made for drummers by a drummer to save rudiment routines with a clean interface and practice them with a metronome.
Built with Flutter for Web and Android.

## Routine Editor
- Customise time signature.
- Add note values up to 32nd notes.
- Choice of snare, kick and rest.
- Support for triplets.
- Add annotations of the stickings (R or L) on every note.
- Edit in sheet music form.
- Unlimited bar count.

## Cloud Saving
- All data is stored both locally and online, allowing syncing between devices with a simple email and password account.
- This is done using Google Firebase Auth and Firestore.
- Full account editing and deletion features.

## Practice Features
- Simple metronome, supporting tempos up to 300 BPM.
- 3 choices of click sounds.
- Gap click to enhance your own internal clock - intervals are fully customisable.
- Accelerating click to train both your endurance and ability to be flexible with the tempo.
- Routines displayed in bold sheet music form for clear, yet traditional visibility.
